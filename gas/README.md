# לייקים וצפיות לאתר — מדריך פריסה

האתר (GitHub Pages — סטטי) סופר **לייקים ("אהבתי")** ו**צפיות** לכל פרויקט.
המספרים נשמרים בגיליון Google Sheets דרך **Google Apps Script** — כך כל הגולשים
רואים את אותם מספרים, ואתם מקבלים פידבק אמיתי על כל פרויקט.

## איך זה עובד מבחינה טכנית

- **קריאת המספרים** — האתר טוען את הספירות מ-`action=counts` ב-**JSONP**
  (עוקף את מגבלת ה-CORS של Apps Script, אין צורך בשרת).
- **לייק / צפייה / ביטול לייק** — נשלחים כבקשת GET "ביקון" (`new Image().src`),
  שאינה דורשת CORS כלל.
- **ספירה הוגנת** — כל מבקר נספר פעם אחת בלבד לכל פרויקט (לפי מזהה מבקר
  ייחודי שנשמר בדפדפן), כך שלייקים וצפיות לא מנופחים.
- **הגיליון** — נוצר אוטומטית בדרייב שלכם בשם
  `ליקים וצפיות - לב טוב דיגיטל`, עם גיליונות `ליקים` ו`צפיות` (תאריך, פרויקט, מזהה מבקר).

## שלבי הפריסה (פעם אחת בלבד)

1. נכנסים ל-**[script.google.com](https://script.google.com)** → **פרויקט חדש**.
2. מדביקים את כל התוכן של **`LikesViews.gs`** בקובץ `Code.gs`.
3. מריצים ידנית פעם אחת את הפונקציה **`setup()`**:
   בשורת התפריטים בוחרים `setup` → **Run** → מאשרים את ההרשאות
   (גישה לגיליונות ולדרייב). זה יוצר את הגיליון.
4. פורסים: **Deploy → New deployment → Web app**:
   - **Execute as:** Me (החשבון שלכם)
   - **Who has access:** Anyone
   - לוחצים **Deploy** ומאשרים.
5. מעתיקים את כתובת ה-**Web app URL**.
6. באתר: פותחים את **`index.html`**, מוצאים את השורה
   `const LIKES_URL = '';` ומדביקים את הכתובת, לדוגמה:
   ```js
   const LIKES_URL = 'https://script.google.com/macros/s/AKfycb...../exec';
   ```
7. דוחפים את השינויים ל-GitHub — והמערכת פעילה.

> **טיפ:** אחרי כל עדכון של הסקריפט (Deploy → Manage deployments → Edit → New version),
> הכתובת נשארת זהה — אין צורך לשנות אותה באתר.

## ניפוי תקלות

- **המספרים לא מופיעים** — ודאו שהכתובת ב-`LIKES_URL` תקינה ושהפריסה היא
  עם גישה ל-**Anyone** (לא "Anyone with Google account").
- **הודעת שגיאה בתשובת השרת** — פתחו את הכתובת
  `LIKES_URL?action=counts` ישירות בדפדפן וראו מה מוחזר.
- **הגיליון לא נוצר** — הריצו שוב את `setup()` ואישרו הרשאות.
